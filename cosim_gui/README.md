# CARLA CoSim Studio（图形界面）

把 CARLA 做成像 CarSim 那样**全部通过界面操作**的平台。原来需要写 Python 脚本完成的操作，现在都是界面上的按钮。

```
┌─ CARLA CoSim Studio (C++ / Dear ImGui) ─┐   本机 TCP     ┌─ backend_server.py (Python) ─┐        ┌─ CARLA 服务器 ─┐
│ 连接 · 世界/天气 · 车辆 · 交通 · 传感器 │ ── JSON 命令 ─▶│ carla 客户端 + CarSim 桥接   │ ─RPC─▶ │ 原版或改版     │
│ CarSim 联合仿真 · 录制回放 · 场景对象   │ ◀─ 实时数据 ── │ (session.py / bridge.py)     │        │ 0.9.16         │
│ 实时画面 · 运行控制 · 曲线 · 日志       │   画面帧        └──────────────────────────────┘        └────────────────┘
└─────────────────────────────────────────┘
```

- **界面**：C++17 + Dear ImGui + GLFW + OpenGL3，编译成一个独立程序。
- **后端**：`carsim_carla_bridge/backend_server.py`，界面启动时自动拉起。所有 CARLA 和 CarSim 操作都在后端完成，用的是已经测试过的 Python 桥接代码。
- **配置**：联合仿真配置是一个 JSON 文件，界面、命令行（`run_cosim.py --config`）和强化学习训练共用同一份。

## 功能

左侧工程树里的页面（和界面上的名字一致）：

| 页面 | 能做什么 |
|---|---|
| 开始 → 连接 | 启动/停止后端，连接 CARLA，显示服务器版本，以及是否支持改版外部动力学接口 |
| 场景 → 地图与天气 | 切换和重载地图；天气预设和 9 个参数滑条；同步模式、固定步长、关闭渲染 |
| 场景 → 交通流 | 按数量和随机种子生成、清除背景车辆和行人，由交通管理器控制 |
| 场景 → 场景对象 | 列出和过滤所有对象，一键删除 |
| 车辆 → 车辆与视角 | 车型表，可一键测量每款车的轮胎半径、轴距、轮距、质量；选择出生点（也是 CarSim 原点）；生成、更换、删除主车；观察视角（自由、跟车、俯视、侧面） |
| 车辆 → 传感器套件 | 预设（单前视 / KITTI / nuScenes / 量产车 / 感知真值）；俯视图 + 侧视图里拖动传感器安装位置（CarSim 车身坐标系：原点在参考点，x 向前、y 向左）；相机、深度（可设最大距离）、语义、实例、激光雷达、毫米波雷达、IMU、GNSS |
| 仿真 → 驾驶模式 | 动力学由谁计算（CarSim 联合仿真 / CARLA 物理）；控制算法（你的 Python 算法）；运行步长、时长、日志 |
| 仿真 → CarSim 动力学 | .sim 和 python_carsim_env 路径；导出变量列表编辑（调整顺序、增删、从 CarSim 粘贴、自动检查必需变量、补全推荐变量）；单位；高度模式、参考点、接口模式；配置文件载入 / 保存 |
| 仿真 → 场景信息 | 像 CarSim 选输出变量一样勾选：障碍物（车辆、行人、停放车辆）的哪些量、车道的哪些量、自车的哪些量、给算法的传感器、记录哪些 CarSim 导出变量；碰撞时停止运行 / 记录并继续 / 不检测；`control(exports, t, dt, scene)` 用法。一切按 CarSim 的坐标系和单位 |
| 数据 → 数据采集 | 采集开关、格式、停止条件（帧数 / 时长 / 容量）、磁盘估算 |
| 数据 → 录制与回放 | CARLA 录制器的开始和停止；回放（起始时间、时长、跟随对象）；查看录制文件信息 |
| 数据 → 实时画面 | 视口画面的开关、分辨率和帧率 |
| 数据 → 数据浏览 | 逐帧浏览采集的数据集（相机 + 标注框、激光雷达俯视图），导出 KITTI / nuScenes |
| 菜单栏 / 工具栏 | 文件、仿真、视图、转到、帮助菜单；运行、暂停、继续、单步、停止（F5 / F6 / F10 / Shift+F5）；仿真读数框（状态灯、时间、车速、实时倍率、进度） |
| 视口（中间） | 主车相机实时画面，左上角切换视角；叠加仪表（车速、方向盘、油门、制动）和小地图（出生点、轨迹、朝向）；多视图（单画面 / 1+3 / 2×2），每个视图可选相机、语义分割、深度、实例分割、激光雷达或毫米波雷达俯视图、套件传感器 |
| 底部面板 | 曲线（车速、前轮转角、悬架、油门 / 制动）；车辆状态（读数、控制条、位姿、四轮表、采集进度）；场景（自车 50 m 内的车辆、行人、停放车辆和车道，CarSim 坐标：俯视图 + 表格，可隐藏停放车辆，碰撞标红）；输出日志 |
| 输出 / 状态栏 | 带时间和级别的日志，可按警告 / 错误过滤；状态栏显示连接、地图、主车、磁盘，运行时变蓝 |

界面布局参照车辆仿真软件（CarMaker、VTD）：左侧工程树，中间是实时 3D 视口和底部面板，右侧是当前页面的属性；各区域之间的分隔条可以拖动；深色（石墨灰）和浅色两套主题。

界面文字用到的汉字：粗体和标题字体只加载常用汉字加上源码里实际用到的字（`src/ui_glyphs.inc`）。**修改界面文字后运行 `python tools/gen_ui_glyphs.py` 重新生成**，否则新出现的生僻字会显示成“?”。

## 编译

依赖库（Dear ImGui 1.91.8、GLFW 3.4、nlohmann/json 3.11.3）已经放在 `third_party/` 里，**编译不需要联网**。

### Windows（VS 2022）
```bat
cd cosim_gui
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
build\Release\carla_cosim_studio.exe
```
中文字体会自动使用系统自带的微软雅黑。

### Ubuntu 22.04
```bash
sudo apt install build-essential cmake libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev fonts-noto-cjk
cd cosim_gui
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/carla_cosim_studio
```

## 首次使用

1. 先启动 CARLA 服务器（原版或改版都可以）。
2. 打开 `carla_cosim_studio`，在"连接"页确认：
   - **Python 解释器**：已安装 `carla` 包的那个 Python，例如虚拟环境里的 `python.exe`。
   - **桥接目录**：`carsim_carla_bridge`。程序会在自身所在目录附近自动查找。
   - 点"保存设置"，下次启动时会自动加载。
3. 点"连接 CARLA"，然后依次到各页面操作。
4. 联合仿真：在"车辆与视角"页选车型和出生点，在"CarSim 动力学"页填写 .sim 路径和导出变量，在"驾驶模式"页选你的控制算法，最后点工具栏的"运行"（F5）。

命令行参数：
- `--python <路径>`：指定 Python 解释器。
- `--backend-dir <目录>`：指定桥接目录。
- `--config <json>`：启动时载入配置。
- `--font <ttf>`：指定中文字体。
- `--tour <目录>`：自动演示并截图，用于测试（包括用真实鼠标点击的步骤）。
- `--size WxH`、`--scale S`：窗口大小、界面缩放（高分屏或高分辨率截图）。
- `--hero <目录> --hero-spawns 0,20,40`：README 封面截图用。晴天 + 背景交通 + CarSim 联合仿真（模拟 CarSim，沿道路行驶）+ 1+3 多视图，从每个出生点各跑一次，每次在第 7 / 10 / 13 / 16 秒各截一张，再从中挑选。例如 `--size 2560x1440 --scale 1.5 --hero /tmp/hero --hero-spawns 0,20`。

## 测试情况（Ubuntu 22.04，CARLA 0.9.16 原版服务器）

- 后端：`tests/test_backend.py` 共 35 项全部通过，覆盖连接、天气、车型尺寸、出生点、主车、交通、传感器（含数据保存）、多视图、录制器、联合仿真（含暂停、单步、继续、完成、启动失败不丢主车）、场景对象（加 `--with-map-switch` 时再测有交通时连续切换地图，共 37 项）；`tests/test_robustness.py` 全部通过（原版包 33 项、改版包 35 项；控制算法出错、NaN、返回值个数、键盘驾驶配大画面不卡死、车贴路面、键盘松手保护、格式错误的请求、CARLA 接口自动识别、测量全部车型、主车被 CARLA 删除、交通车被撞飞不卡死、出生点被占、回放、重新连接清理）；`tests/test_carla_restart.py` 4 项（CARLA 运行中退出再重启）。
- 场景：`tests/test_scene.py` 27 项（CarSim 坐标和单位、只输出勾选的量、碰撞处理、运行记录与采集的采样时刻一致、传感器数据与采集共用、示例算法停车）。
- 界面：`--tour` 自动演示全部 46 个步骤，每个页面都截图检查；运行 / 暂停 / 单步 / 停止、多视图、数据浏览与导出用真实鼠标点击测试。
