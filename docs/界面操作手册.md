## 1. 界面布局

布局参照车辆仿真软件（CarMaker、VTD）：中间是大的实时 3D 画面，四周停靠各个面板。


- **工程树**（左）：按“开始 / 场景 / 车辆 / 仿真 / 数据”分组，点分组名可以折叠。每项右侧是当前值的摘要（地图名、车型、传感器个数、动力学来源、采集开关）。点一项，右侧“属性”面板就显示这一页的设置。除“连接”外，其余页面要先连上 CARLA 才能点。
- **工具栏页签**（场景 / 车辆 / 传感器 / 驾驶 / CarSim / 采集）：按工作流程直接跳到对应页面，和点工程树一样。
- **视口**（中）：主车相机的实时画面。生成主车后会自动打开。
  - 左上角切换视角：跟车、车头、前轮特写、俯视；× 关闭画面（节省带宽）。右上角显示相机名、分辨率、已收到的帧数。
  - **多视图**：左上角的“单画面 / 1+3 / 2×2”切换布局，多个视图同时显示。主视图是上面选的相机，其余每个视图左上角有标签，点标签选择显示内容：相机（跟车 / 车头 / 前轮 / 俯视）、语义分割、深度、实例分割（前视）、激光雷达点云（俯视）、毫米波雷达（俯视），或传感器套件里的任意相机 / 雷达（用它的实际安装位置和参数）。激光雷达按高度着色（蓝低红高），毫米波雷达红色接近、蓝色远离、白色静止，圆环间隔 10 m。
  - 左下角**仪表**：车速、仿真时间、方向盘（按实际转角旋转，下面是角度）、油门和制动条。
  - 右下角**小地图**：灰点是地图上的出生点（大致就是道路），黄圈是选中的出生点，蓝线是本次运行的轨迹，白色三角是主车位置和朝向。
  - 等红灯时画面上方会提示。没有画面时，视口中间会提示下一步该做什么（连接 CARLA / 生成主车 / 打开画面），并给出按钮。
  - 分辨率、套件相机预览在“实时画面”页里设置。
- **底部面板**（中下，Ctrl+L 显示 / 隐藏）：三个页签。
  - 曲线：车速、前轮转向角、悬架行程、油门 / 制动，四张图并排。
  - 车辆状态：车速 / 时间 / 实时倍率 / 帧的读数，控制输入条，位姿（X Y Z、航向、俯仰、侧倾），四轮转向角、转角、悬架表，采集进度。
  - 输出：日志，见第 15 节。
- **属性**（右）：当前页面的全部设置，顶部是“分类 › 页面”和说明，下面是带标题栏的分组，每行左边是属性名、右边是值。菜单“视图 → 属性面板”可以隐藏它，让视口更大。
- **分隔条**：工程树、视口、底部面板、属性面板之间的分隔线都可以用鼠标拖动调整大小。
- **状态栏**：仿真运行时变成蓝色，一眼就能看出是否在运行。
- **鼠标悬停**在带 `?` 的图标上会显示说明。
- **所有设置**（驾驶、传感器、采集、CarSim）保存在一份 JSON 配置里：Ctrl+S、工具栏“保存”，或“CarSim 动力学”页底部的“配置文件”分组。

## 3. 连接

**CARLA 服务器**
- 主机地址：一般填 `localhost`。
- RPC 端口：原版 CARLA 默认 `2000`；按本项目脚本启动的改版 CARLA 是 `3000`。
- 点 **连接 CARLA**。成功后显示服务器 / 客户端版本、当前地图，以及“外部动力学接口”是否可用：
  - 绿色“改版 CARLA：可用”：一帧一次下发完整状态，速度 / IMU 读数真实，悬架动画可用。
  - 黄色“原版 CARLA：兼容模式”：画面同步效果相同，但 `get_velocity()`、IMU 等速度类读数为 0，没有悬架动画。

**Python 后端**
- Python 解释器：装有 `carla` 包的 Python。写完整路径最稳妥，例如 `.../venv/bin/python` 或 `...\venv\Scripts\python.exe`。
- 桥接目录：本仓库的 `carsim_carla_bridge` 目录。程序会在自身所在目录附近自动查找。
- 后端端口：默认 `57100`，一般不用改。
- 自动启动：打开界面时自动拉起后端。
- **启动后端 / 停止后端**：手动控制。停止后端时会先清理 CARLA 里的主车、传感器和交通。
- **保存设置**：以上设置保存到程序目录下的 `cosim_studio_prefs.json`，下次自动加载。

> 关闭界面时，后端会自动清理 CARLA 里的主车、传感器、交通并退出；即使界面异常退出，后端检测到断开后也会自动清理。

## 4. 地图与天气

**地图**：下拉选择 → **加载地图**（约 5–30 秒）；**重载当前地图** 恢复初始状态。
切换地图会清掉主车、交通和传感器。带 `_Opt` 后缀的是分层地图，可以隐藏建筑等图层，更省显存。

**天气与光照**
- 8 个快速预设：晴天正午、多云、湿滑路面、大雨、日落、夜晚、雨夜、黄昏中雨。
- “全部预设”下拉里有 CARLA 所有内置天气，选好后点“应用”。
- 9 个参数滑条：太阳高度角（负数 = 夜晚）、太阳方位角、云量、降雨、积水、路面湿度、风力、雾浓度、雾起始距离 → 点 **应用天气参数**。

**仿真设置**
- 同步模式：服务器每次 tick 才前进一帧。运行仿真时会自动切到同步，结束后恢复成这里的设置。
- 固定步长：同步模式下每帧的仿真时间，0 = 可变步长。
- 关闭渲染：只算物理不渲染，速度快很多，但**相机类传感器没有图像**。
- 空闲时持续推进：同步模式且没有仿真在跑时，由后端持续 tick，否则服务器画面会停住。
- **应用** 使设置生效；**刷新** 读取服务器当前状态。

## 5. 交通流

- 车辆数 / 行人数：0–150。
- 随机种子：同一地图加同一种子 = 同样的交通布置，便于复现实验。
- 只生成小汽车：不生成摩托车、自行车和卡车。
- **生成交通** / **清除交通**。交通车辆会避开主车出生点 10 m 以内的位置，由 CARLA 交通管理器驾驶（遵守信号灯、会跟车）。

## 6. 场景对象

列出场景中的车辆、行人、传感器等（不含信号灯和观察相机）。
- 过滤：输入 `vehicle.*`、`walker.*`、`sensor.*`，或点旁边的快捷按钮。
- 表格显示 ID、类型、角色（`hero` = 主车，`autopilot` = 交通车）、位置。
- 每行的垃圾桶图标删除该对象（删除主车等同于“删除主车”）。

## 7. 车辆与视角

**车型**
- 搜索框按名字过滤。
- **测量全部车型尺寸**：每款车在高空临时生成一次，测出轮胎半径、轴距、轮距、长宽高、质量、最大转角，大约需要 1–2 分钟。
  用来挑选**和 CarSim 模型尺寸接近**的车型——两边的轮胎半径、轴距越接近，画面越逼真。
- 点表格里的一行即选中该车型。

**出生点（也是 CarSim 坐标原点）**
- 左边是地图上所有出生点的俯视图，**点击选择**；也可以直接输入编号。
- CarSim 的 (0, 0, 0)、航向 0 会对齐到这个出生点。
- 自定义车身颜色：勾选后用取色器选。
- **生成主车 / 更换主车 / 删除主车**。
- “用 CARLA 自动驾驶试开”：不运行仿真时，快速看一下车辆和传感器效果。

**服务器观察视角**：控制 CARLA 服务器窗口里的相机（自由 / 跟车 / 俯视 / 侧面）。服务器离屏运行时看不到窗口，请用“实时画面”页。

## 8. 传感器套件

**预设方案**：安装位置会按当前车型的长宽高自动计算；车型没测量过时按 4.8 × 2.0 × 1.5 m 的轿车计算。

| 预设 | 组成 | 用途 |
|---|---|---|
| 单前视相机 | 1 个 RGB 相机 1280×720，挡风玻璃上方 | 车道保持、强化学习 |
| KITTI 风格 | 2 个 RGB 1242×375 双目（基线 0.54 m）+ 64 线激光雷达 + GNSS + IMU | 3D 检测、双目深度 |
| nuScenes 风格 | 6 个 RGB 1600×900 环视 + 32 线激光雷达 + 5 个毫米波雷达 | 环视感知、BEV |
| 量产车风格 | 前视主相机 / 广角 / 长焦 + 4 个侧视 + 后视 + 前向毫米波雷达 | 纯视觉方案 |
| 感知真值 | 同一位置的 RGB + 深度 + 语义 + 实例 | 分割、深度估计训练 |

**添加传感器**：相机、深度、语义、实例、激光雷达、毫米波、IMU、GNSS。

**安装位置**
- 俯视图：车头朝上，x 向前、y 向右；扇形 = 相机 / 雷达的视场角，圆环 = 激光雷达。
- 侧视图：车头朝右，z 向上；扇形 = 相机的垂直视场角（含俯仰）。
- **按住传感器圆点拖动**即可改位置，网格间距 1 m。坐标原点是车辆原点（车底中心、地面高度）。

**传感器列表**：勾选框启用 / 停用；点名称选中；最右一列是这个传感器每帧大约多少 MB。

**属性分组**（选中传感器后出现）
- 名称（也是输出文件夹名）；x / y / z、航向（0 朝前、90 朝右、180 朝后）、俯仰（负数 = 向下看）、侧倾：可以拖动数值，也可以双击直接输入。
- 相机：分辨率预设（640×360 到 2560×1440，以及 KITTI 的 1242×375）、宽、高、水平视场角。
- 激光雷达：线数 16 / 32 / 64 / 128、量程、每秒点数、上下视场角。采集时每帧自动输出完整一圈扫描。
- 毫米波雷达：水平 / 垂直视场角、量程、每秒点数。
- **预览这个相机**：用它的实际安装位置和视场角，在“实时画面”里看它拍到什么（需要先生成主车）。
- **复制 / 删除**。

**数据量估算**：每帧 MB、写盘速率 MB/s、每小时 GB、本次最多 GB，以及和磁盘剩余空间的对比条。

## 9. 驾驶模式

**车辆动力学由谁计算**
- **CarSim 联合仿真**：你的控制算法控制 CarSim 的车，CarSim 计算动力学；CARLA 每帧把车放到 CarSim 算出的位置和姿态（车轮转角、转速、悬架也照 CarSim），自己不算动力学，只负责场景、交通、传感器和画面。
- **CARLA 物理**：用 CARLA 自带的 PhysX 车辆模型，不需要 CarSim。

**控制算法（CarSim 联合仿真）**

默认就是“**我的控制算法**”：每帧把 CarSim 的全部导出变量交给你的 Python 算法，算法返回的油门、制动、方向盘送回 CarSim（.sim 里的 REPLACE 导入变量）。

- **算法文件 .py**：你的算法文件。相对路径以 `carsim_carla_bridge` 目录为准，也可以填绝对路径。**每次点“运行”都会重新加载**，改完代码直接再点运行，不用重启界面。
- **入口**：文件里的类名（默认 `Controller`）或函数名。

```python
# 例：C:\carla-cosim-studio\carsim_carla_bridge\controllers\my_controller.py
class Controller:
    def reset(self):                       # 可选，每次运行开始调用一次
        self.integral = 0.0

    def control(self, exports, t, dt):     # 每帧调用一次
        vx = exports["Vx"]                 # 按变量名取 CarSim 导出变量（CarSim 单位）
        ...                                # 你的算法
        return [throttle, brake, steer_sw] # 按 .sim 里导入变量的顺序
```

- `exports`：字典，键是“CarSim 动力学”页导出变量列表里的名字，值是 CarSim 单位（`Vx` km/h、`Yaw` deg ……）。
- `t`：CarSim 当前时间（s）；`dt`：控制周期 = “仿真步长”。
- 返回值：按 .sim 里导入变量的顺序。python_carsim_env 默认是 `[油门 0~1, 制动, 方向盘转角 deg（左正）]`。
- 算法里可以 `import` 同目录的其他文件，也可以直接 `import` python_carsim_env 里的模块。
- 出错时（文件不存在、入口名不对、算法抛异常）运行会停止，错误信息显示在日志里。
- 自带两个示例：`controllers/example_controller.py`（PI 定速 + 蛇形转向，拿来改）；`controllers/simple_path_follower.py`（把你项目里的 SimplePathFollower 接进来，需要导出 `LatErr`）。

**测试用驾驶方式**（折叠栏，还没有算法时检查链路用，平时不用管）

| 方式 | 说明 |
|---|---|
| 演示（开环） | 固定的加速 + 蛇形 + 制动，看 CARLA 的车是否跟着 CarSim 动、转向方向对不对 |
| 路线跟随 | 程序在 CARLA 路网上规划路线，算出油门、方向盘送给 CarSim；可设目标车速、目的地出生点 |
| 键盘驾驶 | W / ↑ 油门，S / ↓ 制动，A、D / ←、→ 转向，手动开 CarSim 的车 |

路线跟随和键盘驾驶下有“制动输入比例”：0–1 的制动指令乘以这个系数再送给 CarSim，CarSim 制动输入是主缸压力（MPa）时设 10 左右。

**驾驶方式（CARLA 物理）**：路线跟随、CARLA 自动驾驶（交通管理器：遵守信号灯、跟车、变道；可设相对限速 %、忽略红绿灯）、键盘驾驶。

**运行设置**
- 仿真步长：CARLA 每帧的仿真时间。CarSim 每帧内部积分 `步长 / t_step` 步，**最好是 t_step 的整数倍**（例如 t_step = 0.001 时用 0.02）。
- 运行时长：默认 0 = 一直运行，直到点“停止”。设了时长（例如 20 s），到时会自动结束并让主车停车，画面上方会出现黄色提示条说明原因；所以如果看到车在绿灯前不走、工具栏显示“已完成”，就是运行时长到了。
- 日志 CSV：每帧记录 CarSim 位姿和 CARLA 实际位姿，用来检查同步误差；留空 = 不记录。

> 键盘驾驶时，界面窗口需要有焦点，并且光标不能停在输入框里。

## 10. CarSim 动力学

**CarSim 模型**
- 模拟 CarSim：没有 CarSim 许可证时勾选，用内置的简单车辆模型测试整条链路。
- `.sim` 文件：CarSim 生成的仿真文件（Windows 上一般在 CarSim 数据库目录下）。
- python_carsim_env 目录：CarSim 的 Python 接口所在目录。

**导出变量（顺序必须与 .sim 一致）**
- 绿色提示 = 必需变量齐全；红色提示 = 缺少哪些变量。蓝色变量名 = 必需变量。
- ↑ ↓ 调整顺序，✕ 删除，在输入框里写名字再点“添加”可追加一个。
- 从 CarSim 的 Export 列表复制，粘贴到文本框，点 **用粘贴内容替换**（空格、换行、逗号都能作分隔符）。
- **补全推荐变量**：追加速度、角速度、四轮转速、悬架行程等推荐变量（CarSim 里也要按同样顺序加上）。
- 每个变量的含义见 [CarSim 导出变量清单](../carsim_carla_bridge/docs/CarSim导出变量清单.md)。

**单位与坐标**
- 角度、速度、角速度、车轮转速、悬架行程的单位（默认是 CarSim 用户单位：deg、km/h、deg/s、rpm、mm）。
- 高度模式：使用 CarSim 高度 / 贴合 CARLA 路面（CarSim 路面和 CARLA 地图高度不一致时用后者）。
- 参考点在前轴中心：CarSim 的 Xo / Yo / Zo 默认在前轴中心的地面处；不是的话取消勾选并填写偏移。
- CARLA 接口：自动 / 强制改版接口 / 强制原版兼容。
- 方向盘满量程：方向盘转这么多度，对应 steer = ±1。

**配置文件**：载入 / 保存 / 恢复默认。同一个 JSON 也能给命令行用：`python run_cosim.py --config <文件>`。

## 11. 数据采集

1. 在“传感器套件”页配好传感器。
2. 在本页打开 **运行时采集数据**。打开时如果仿真步长小于 0.05 s，会自动把采集频率设成 10 Hz。
3. 设置输出目录、场景名称（留空 = 按时间自动命名）。
4. **采集内容与格式**
   - 采集频率：同时决定仿真步长（= 1 / 频率）。KITTI、nuScenes 等数据集一般用 10 Hz；超过 20 Hz 会提示数据量大。
   - 每 N 帧存一次：仿真频率高、但不需要每帧都存时用。
   - RGB 格式：JPG（大小约为 PNG 的 1/4）或 PNG（无损）；JPG 质量 50–100。深度 / 语义 / 实例图始终是无损 PNG。
   - 点云格式：`.bin`（KITTI 格式，float32 x, y, z, 强度）或 `.npy`。
   - 真值标注：保存范围内车辆和行人的 3D 框、类别、ID、速度。
5. **停止条件（至少设一项）**：最多帧数、最长时间（真实时间）、最大容量 GB。磁盘剩余少于 10 GB 时也会自动停止。
6. 看 **数据量估算** 确认占用，再点顶部 **运行**。右侧“采集进度”会显示已采帧数、已写入 MB、实际写盘速率。

**输出结构**（页面底部也会按当前套件实时显示）
```
<输出目录>/<场景名>/
  meta.json               地图、天气、传感器套件、采集设置、数据格式说明
  calib.json              每个传感器：extrinsic_sensor_to_ego（4×4）、相机内参 K、安装位姿、属性
  cam_front/000123.jpg    相机（文件名 = 帧号，同一帧所有传感器编号相同）
  lidar_top/000123.bin    激光雷达：float32 [x, y, z, intensity]，激光雷达自身坐标系（CARLA 轴向）
  radar_front/000123.csv  毫米波雷达：每行 [速度 m/s, 方位角 rad, 俯仰角 rad, 距离 m]
  cam_depth/000123.png    深度：depth_m = (R + G*256 + B*65536) / (256^3 - 1) * 1000
  cam_semantic/000123.png 语义：R 通道 = CARLA 语义标签
  cam_instance/000123.png 实例：R = 语义标签，G + B*256 = 物体 ID
  labels/000123.json      objects：id、type_id、class、center_ego、extent、yaw_ego、world、velocity
  ego/000123.json         frame、timestamp、pose、velocity、angular_velocity、acceleration、control，
                          imu / gnss（套件里有这两个传感器时），carsim（CarSim 模式下的全部导出变量）
```
坐标系：主车坐标系原点在车底中心、地面高度，x 向前、y 向右、z 向上（CARLA / UE 的左手系），单位米。

## 12. 录制与回放

- **开始录制 / 停止录制**：CARLA 录制器会记录整个场景（所有车辆、行人、信号灯），文件保存在 **CARLA 服务器所在的机器**上。
- **回放**：可设起始时间、时长（0 = 全部）、相机跟随的对象 ID。
- **文件信息**：显示录制文件里的帧数、对象等。
- 用法举例：先录一段场景，之后换一套传感器，在回放时重新采集，不用重跑仿真。

## 13. 实时画面

- 视角：跟车、车头、前轮特写（看转向、车轮转动、悬架跳动最清楚）、俯视。
- 套件相机：用传感器套件里某个 RGB 相机的实际位置和视场角来预览。
- 分辨率：480×270 到 1280×720，默认 960×540。分辨率越高画面越清楚，但传给界面的数据量越大。
- **多视图**：布局（单画面 / 1 大 + 3 小 / 2 × 2），以及视图 1–3 各自显示什么（同视口标签里的选项）。2 × 2 时每个视图 640×360，1+3 时小视图 480×270；视图越多，CARLA 渲染和传输越重。
- **打开画面 / 关闭画面**。画面显示在中间的视口里；生成主车后会自动打开。

## 14. 视口仪表与底部面板

- 视口左下角仪表：车速、仿真时间、方向盘（按实际转角旋转）、油门和制动条；右下角小地图显示出生点、本次轨迹和主车朝向；等红灯时画面上方会提示“正在等红灯”。
- 底部面板“车辆状态”页签：
  - 车速、仿真时间、实时倍率、帧。
  - 油门、制动、转向条（转向居中为 0，向右为正）。
  - 位置、航向、俯仰、侧倾。
  - 四轮表：转向角、转角（车轮自转的累计角度）、悬架行程（压缩为正）。
  - 采集进度（采集时显示）。
- 底部面板“曲线”页签：车速、左右前轮转向角、四轮悬架行程、油门 / 制动。鼠标滚轮缩放，拖动平移，双击恢复。

## 15. 状态栏与输出

- 状态栏圆点颜色：绿色 = 正常，黄色 = 启动中，红色 = 未连接。仿真运行时整条状态栏变成蓝色。
- 地图、主车 ID、输出目录所在磁盘的剩余空间（少于 20 GB 时变黄）。
- 忙碌提示（加载地图、测量车型等）。
- 右侧有错误时显示“N 个错误”，点一下打开输出窗口。
- **输出**（底部面板的第三个页签）：每条信息带时间和级别图标；可以按“全部 / 警告 / 错误”过滤，“清空”删除全部信息。有错误时页签上显示错误数，状态栏右侧点“N 个错误”会直接打开这个页签。

## 16. 常用操作流程

**A. 先不接 CarSim，跑通整条链路**
连接 → 车辆与视角（选车、生成主车）→ 驾驶模式（CarSim 动力学 + 路线跟随）→ CarSim 动力学（勾选“模拟 CarSim”）→ 实时画面（打开画面）→ 点顶部“运行”。

**B. 接入真实 CarSim**
在 CarSim 里配置好导出变量 → CarSim 动力学页：填 .sim 文件、python_carsim_env 目录，按 .sim 里的顺序填导出变量（看到绿色提示）→ 驾驶模式页选“CarSim 联合仿真”，算法文件填你的 .py → 运行。先打开“日志 CSV”，检查 CarSim 与 CARLA 的位姿误差是否为 0。

**C. 采集一个小数据集**
地图与天气（选地图和天气）→ 交通流（例如 30 辆车、20 个行人）→ 车辆与视角（选车）→ 传感器套件（加载 nuScenes 预设）→ 驾驶模式（CARLA 物理 + CARLA 自动驾驶）→ 数据采集（打开、10 Hz、最多 200 帧）→ 运行。
